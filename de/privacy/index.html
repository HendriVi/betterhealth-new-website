Datenschutzhinweise zur Website · Aktualisiert am 25. September 2026.

Besuch der Website

Diese statische Website wird auf GitHub Pages bereitgestellt. Wir haben keine Werbepixel, Drittanbieter-Analyse, Social-Media-Einbettungen oder extern geladenen Schriften hinzugefügt. GitHub kann technische Zugriffsinformationen einschliesslich IP-Adressen zur Bereitstellung und Absicherung des Hosting-Dienstes verarbeiten.

GitHub Datenschutzerklärung ↗

Formulare und Reflexionshilfe

Formular und Reflexionshilfe laufen in Ihrem Browser. Ihre Eingaben werden durch diese Website weder an einen Server übermittelt noch durch unseren Code in Cookies oder Browserspeichern gespeichert. Ihr Browser kann eigene Funktionen zum automatischen Ausfüllen anbieten.

E-Mail-Anfragen

Mit „E-Mail-Programm öffnen“ wird der vorbereitete Text an Ihr E-Mail-Programm übergeben. Sie entscheiden über den Versand. Ihr E-Mail-Anbieter verarbeitet die Nachricht gemäss seinen Bedingungen. Wenn Sie eine Anfrage senden, erhält der Empfänger Ihre Angaben, um sie beantworten zu können. Beschränken Sie die erste E-Mail auf allgemeine Angaben und lassen Sie Gesundheitsunterlagen weg.

Externe Links und Teilen

Externe Artikel und Ziele geteilter Links haben eigene Datenschutzpraktiken. Die Teilen-Schaltflächen nutzen auf Ihren Wunsch die Teilen-Funktion Ihres Geräts oder kopieren einen Link. Externe Inhalte werden nicht eingebettet oder automatisch geladen.

Fragen zu Ihren Informationen

Für Fragen zu einer Anfrage oder für Auskunft, Berichtigung oder Löschung gesendeter Angaben kontaktieren Sie hello@betterhealth.ch. Identität des Verantwortlichen, Aufbewahrung und ein allfälliger Umgang mit klinischen Daten sind mit dem zuständigen Anbieter zu klären, bevor sensible Informationen geteilt werden.
